# Synthetic data policy

Every included record was generated by software. **No real experimental observations were supplied.**

1. Keep `SYNTHETIC_NOT_OBSERVED` in every source row, each manifest and each analysis summary.
2. Keep `SYNTHETIC — NOT OBSERVED` visibly on every figure and demonstration report.
3. Do not remove these labels, mix these rows with observed measurements, or cite generated estimates as animal/product evidence.
4. Do not invent completed experiments, ethical approvals, reviewers, funding, qualifications, affiliations, consent or outcomes.
5. The user may compare a synthetic pattern with later observations, but verification does not retroactively turn generated rows into observations. Collect and store real records independently with instrument/source traceability.
6. Source hashes record integrity; they do not establish truth.
7. Null/modest/plateau parameters are illustrative planning assumptions. Publish all fixed scenarios if demonstrating the code. Do not select seeds for significance.
8. A real study requires its own welfare review, measurement protocol, sample-size justification, preregistered estimands, missingness rules and validated analysis before results are interpreted.

The public repository is software plus synthetic examples and protocol notes. It is not evidence of a completed animal experiment and must not be described as one in a manuscript.
